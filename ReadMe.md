Description:  
  
This application creates a vault to securely store website usernames and passwords  
Passwords are encrypted and not stored as plaintext. A secure master password is required to unlock the vault.  
  
The first time the program is ran it prompts the user to enter a password, this password is then used to create the key used for encryption and decryption of vault passwords.  
  
The program will create 3 files necessary for functionality and automatically store them in the folder in which the Credentail_Vault.py file is in.
